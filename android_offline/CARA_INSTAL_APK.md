# Cara Mengambil & Memasang APK Offline AGOS Smart Diagnostik v2.0.0 di HP Android

Aplikasi **AGOS Smart Diagnostik (Mode Offline v2.0.0)** sudah dibangun dengan **logo ikon baru resmi AGOS** dan seluruh pembaruan sistem (sebelum Poin 4) agar berjalan **100% tanpa internet dan tanpa server**.

### Pembaruan pada APK Offline v2.0.0:
- **Logo Ikon & Splash Screen Baru:** Ikon aplikasi layar utama Android (Adaptive Icon, Round, Legacy) serta layar pembuka memakai logo heksagon AGOS baru secara penuh tanpa terpotong.
- **66 Generasi & 174 Kode Mesin (Asia, Eropa, & China):** Lengkap termasuk Toyota Innova Bensin (`1TR-FE` / alias `1TR-VE`), Innova Reborn (`2GD-FTV`), Fortuner, Pajero (`4N15`), Ertiga/XL7 (`K14B`/`K15B`), BMW, Mercedes-Benz, VW/Audi, Peugeot, Wuling, Chery, DFSK, MG, BYD, GWM, BAIC, Jetour + **Tombol `🔍 Cari` Kamus Kode Mesin**.
- **+85 Kode DTC Modern & Anti-Salah Vonis:** Mencakup Diesel Common-Rail (`P0087`–`P0093`, `P0299`, `P0401`, `P062D`, `P2002`), VVT/VANOS (`P0011`–`P0017`), Hybrid/EV (`P0A80`, `P0AA6`, `P0A93`), dan CAN Bus (`U0100`–`U0121`), lengkap dengan filter jenis bahan bakar, cutoff `< 25%`, & **Peringatan Keselamatan HV 1000V**.
- **Live Data Scanner Adaptif (`Bensin` | `Diesel` | `Hybrid/EV`) & Guardrail Wiring + Impor Paket Manual Kustom.**
- **Mode Kepala Bengkel (PIN Pengaman — awal: `1234`) & Backup/Restore Database 1-Klik.**
- **Tampilan HP Rapi + Layar Horizontal/Vertikal:** 0 scroll samping di semua ukuran HP & gambar simulasi penuh (*Full-View*).

## Langkah 1 — Mengambil File `.apk`
1. File siap pasang tersedia langsung di folder proyek Anda: **`AGOS-Smart-Diagnostik-Offline.apk`**.
2. Atau unduh langsung dari GitHub Releases:
   👉 **[https://github.com/BAGUSW085/agos-smart-diagnostik/releases/tag/v2.0.0-offline](https://github.com/BAGUSW085/agos-smart-diagnostik/releases/tag/v2.0.0-offline)**

## Langkah 2 — Memasang APK di HP Android
1. Kirim file **`AGOS-Smart-Diagnostik-Offline.apk`** ke HP Android Anda (lewat WhatsApp, kabel USB, atau Google Drive).
2. Ketuk file **`AGOS-Smart-Diagnostik-Offline.apk`** di HP Anda (jika sebelumnya sudah terpasang versi lama, pilih **Update / Perbarui**).
3. Jika muncul peringatan *"Instal aplikasi yang tidak dikenal"*, aktifkan **"Izinkan dari sumber ini"**.
4. Ketuk **Instal (Install)** → **Buka (Open)**.
